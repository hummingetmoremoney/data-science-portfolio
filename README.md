# data-science-portfolio

Portfolio site for Cui Hengming, published with GitHub Pages.

- `index.md` — the page itself; GitHub Pages treats it as the entry file.
- `images/` — figures used on the page, exported from the project repository.
- `_config.yml` — theme and site title.

Published from the `main` branch, root folder, under **Settings → Pages**.
Live site: https://hummingetmoremoney.github.io/data-science-portfolio/

Project repository: https://github.com/hummingetmoremoney/data-science-project
